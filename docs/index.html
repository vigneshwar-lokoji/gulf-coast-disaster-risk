Choosing a threshold

Recomputed live over all held-out hazard rows. Raising the threshold cuts workload and raises precision, but you miss more declarations. There is no free lunch here.

ThresholdCounties flagged / year PrecisionRecall Lift vs base rate

Base rate is — the share of hazard days that end in a declaration anyway. A lift of 2.0x means the flagged list is twice as dense in real declarations as an unranked list of the same length. Above about 12% the flagged list shrinks to a few dozen rows and precision becomes noise rather than a trend — read the top of this range with care.
