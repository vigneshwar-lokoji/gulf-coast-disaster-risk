How the model works, and where it holds up

How much warning does it actually buy?

Reporting one number for a “1 to 3 day forecast” hides the thing a user needs most. “Something starts in the next three days” is a much easier question than “something starts three days from now”, so a single pooled score quietly flatters the longer leads. Every lead below therefore has its own model, trained and scored on its own target, and each is measured against the strongest single-feature baseline for that same target — which gets harder to beat as the signal weakens.

Gradient boosting vs. the Temporal Fusion Transformer

Both were trained on the same panel, the same splits and the same label, so the comparison is like for like. The transformer sees a 30-day encoder window per county and is trained with a positive-class weight of 50, then calibrated with isotonic regression fitted on validation so its probabilities can be read as probabilities. It is the heavier model by a wide margin — hours on an A100 against minutes of boosting.
