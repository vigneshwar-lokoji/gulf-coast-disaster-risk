How the model works, and where it holds up

Does it work somewhere it has never been?

The usual way to report a score is to test on counties the model already trained on. That measures memory, not skill. Here each state is removed from training entirely and then scored, so the number below is what the model is worth in territory it has never seen.

Model choice per hazard

Every model was tested against simple baselines before being accepted. For floods, gradient boosting lost to a single rainfall ratio, so the simpler model was kept. That is a result, not an oversight.
